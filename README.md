## 📦 Aplikasi

### [`image-upscaler-pro/`](./image-upscaler-pro)
Aplikasi upscale gambar (single & batch) dengan GUI modern (CustomTkinter), dark/light mode, drag & drop, preview before/after, dan dual engine **Real-ESRGAN (AI)** + **Lanczos (klasik)**. Target utama: Windows.

```powershell
cd image-upscaler-pro
pip install -r requirements.txt
python run.py
```
